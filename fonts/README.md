# Fonts

All typefaces here are licensed under the SIL Open Font License 1.1. The OFL requires the license text
to accompany any redistribution — each family's `OFL.txt` (which names its copyright holder and
Reserved Font Name, if any) is in `licenses/`.

Variable fonts are as downloaded from google/fonts. `ArchivoCond.ttf` and `ArchivoSemiCond.ttf` are
static instances of Archivo at wdth 70 / 84, produced with `fonttools varLib.instancer`, because
WeasyPrint ignores `font-stretch`. Under the OFL such derivatives must not use a Reserved Font Name;
Archivo declares none, and the instances are renamed to avoid confusion with the upstream family.
